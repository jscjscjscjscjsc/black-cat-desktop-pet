==============================
        🐱 黑猫桌宠 🐱
==============================

【启动方式】
  双击「启动黑猫.bat」即可启动。
  首次启动会自动安装依赖包，需要联网，请稍候。

【系统要求】
  - Windows 10/11
  - Python 3.8 或更高版本（安装时勾选 Add Python to PATH）
  - 网络连接（首次安装依赖 + TTS语音合成需要联网）

【互动方式】
  - 双击桌宠：随机互动 + 语音对话
  - 右键桌宠：打开功能菜单
  - 右键托盘图标（右下角小图标）：显示/隐藏/退出
  - 喂食、抚摸、逗猫等操作可在菜单中选择
  - 长时间不理会，猫咪会自己休息

【表情与动作】
  - normal（趴着放松）：默认状态
  - happy（幸福侧躺）：开心、喂食后
  - sleepy（理毛慵懒）：困倦、无聊时
  - surprised（警觉炸毛）：惊吓时
  - sad/alert（抬头警惕）：关注时
  - playful/坐看（坐着看你）：互动时
  平时耳朵会抖动，有呼吸动画。

【语音】
  默认使用 edge-tts 晓伊音色，语速放慢、音调略低，呈现慵懒傲娇猫咪风格。
  如果需要使用豆包语音（火山引擎TTS），请编辑 ui/tts_engine.py 文件，
  填入正确的 APPID 和 Token 后将 USE_DOUBAO 设为 True。

【注意事项】
  1. 启动后黑猫出现在桌面右下角
  2. 如果看不到，检查系统托盘是否有黑猫图标
  3. 关闭控制台窗口不会退出桌宠，需右键→退出
  4. 如需开机自启，在菜单中开启

【常见问题】
  Q: 提示"未找到Python"？
  A: 请安装 Python 3.8+，安装时勾选"Add Python to PATH"

  Q: 依赖安装失败？
  A: 检查网络，或手动执行：pip install PyQt5 edge-tts Pillow pywin32 requests

  Q: 没有声音？
  A: 检查系统音量，首次TTS需要联网下载语音文件
