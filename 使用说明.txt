==============================
        🐱 黑猫桌宠 🐱
==============================

【启动方式】
  双击「启动黑猫.bat」即可启动。
  首次启动会自动安装依赖包，需要联网，请稍候。

【系统要求】
  - Windows 10/11
  - Python 3.8 或更高版本（安装时勾选 Add Python to PATH）
  - 网络连接（首次安装依赖 + TTS语音合成需要联网）

【互动方式】
  - 双击桌宠：随机互动 + 语音对话
  - 右键桌宠：打开功能菜单
  - 右键托盘图标（右下角小图标）：显示/隐藏/退出
  - 喂食、抚摸、逗猫等操作可在菜单中选择
  - 长时间不理会，猫咪会自己休息

【表情与动作】
  - normal（趴着放松）：默认状态
  - happy（幸福侧躺）：开心、喂食后
  - sleepy（理毛慵懒）：困倦、无聊时
  - surprised（警觉炸毛）：惊吓时
  - sad/alert（抬头警惕）：关注时
  - playful/坐看（坐着看你）：互动时
  平时耳朵会抖动，有呼吸动画。

【语音】
  默认使用 edge-tts 晓伊音色，语速放慢、音调略低，呈现慵懒傲娇猫咪风格。
  如果需要使用豆包语音（火山引擎TTS），请编辑 ui/tts_engine.py 文件，
  填入正确的 APPID 和 Token 后将 USE_DOUBAO 设为 True。

【注意事项】
  1. 启动后黑猫出现在桌面右下角
  2. 如果看不到，检查系统托盘是否有黑猫图标
  3. 关闭控制台窗口不会退出桌宠，需右键→退出
  4. 如需开机自启，在菜单中开启

【常见问题】
  Q: 提示"未找到Python"？
  A: 请安装 Python 3.8+，安装时勾选"Add Python to PATH"

  Q: 依赖安装失败？
  A: 检查网络，或手动执行：pip install PyQt5 edge-tts Pillow pywin32 requests

  Q: 没有声音？
  A: 检查系统音量，首次TTS需要联网下载语音文件

==============================
  酒馆战棋军师功能（企鹅版）
==============================
企鹅版（咕嘎企鹅）在桌宠基础上内置酒馆战棋军师能力，开一把炉石传说酒馆战棋即可使用。

【实时胜率解读】（战斗阶段自动触发）
  - 战斗开始，咕嘎自动读取游戏日志，模拟 2000 场算出胜率/平局/败率
  - 不再只念数字：会解读"为什么是这个胜率"——谁是最先倒的弱点、
    对面最大威胁是谁、我方输出担当/胜负手是谁，再由 AI 军师给针对性打法

【对手阵容分析】
  - 自动识别对手流派（野兽/机械/鱼人/亡灵/恶魔/海盗…）与置信度
  - 点出核心组件、威胁（烈毒/圣盾/复生数量）、弱点与应对（站位/留牌）

【招募阶段阵容展望】
  - 招募阶段【点击企鹅】或右键菜单「🔮 阵容展望」：
    咕嘎会分析你当前阵容方向（置信度+依据）、还缺的核心组件、
    成型阵容模板、成型期与下一步建议（升/买/刷/转），再由 AI 军师展开讲
  - 25 秒冷却防刷屏；战斗中点击仍是正常互动

【其他军师功能】
  - 右键「看我的棋盘」：日志优先、视觉（截屏AI识别）兜底分析对局
  - 右键「分析对局」：截屏让咕嘎看棋盘给建议
  - 右键「一键拔线（F1）」：战斗开始后强制断开对局连接跳动画（需管理员权限）
  - 打字对话/按住说话：随便问战棋问题（流派、站位、S14 机制都行）

【战绩记忆（最近5场）】
  - 每把酒馆战棋分出最终结果（吃鸡/出局/名次）后，咕嘎自动记住，只保留最近 5 场
  - 对局结束自动调侃播报：连胜夸你，连败损你（可爱不刻薄）
  - 右键「最近战绩」随时查看 + 被调侃
  - 聊天问"我最近战绩怎么样"也会带上战绩数据调侃
  - 战绩存在 data/match_history.json，重启桌宠不丢

【战棋相关配置】
  - ai_config.json：DeepSeek 对话 API Key、智谱视觉 Key（看棋盘用）
  - knowledge/battlegrounds/：知识库（基础机制/流派/战术/克制对位/主播档案），可自行增删 JSON 知识块
