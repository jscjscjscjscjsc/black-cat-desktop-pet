# 咕嘎持续语音升级

2026-10-19：默认“长语音 · 边聊边执行”已恢复阿里端到端模型，并通过原生 `ask_deepseek` 工具调用接入 DeepSeek 问答和任务执行。阿里负责实时通话和原生音频播报，DeepSeek 负责实质问答、推理及软件操作。对话窗内新增“关闭”、语音设置、静音和打断按钮；关闭或 Esc 停止通话但保留桌宠。详见 [智能体生态说明](agent-ecosystem.md)。下述平台、音色、额度保护与耳机/外放机制继续沿用。

当前默认平台：千问 AI 平台 `platform.qianwenai.com`，模型 `qwen-audio-3.1-realtime-plus`，音色 `longanqian_v3.1`。
调用地址：`wss://maas.qianwenaiapi.com/api-ws/v1/realtime`。只需该平台的通用 API Key，无需业务空间 ID。
配置中可另选阿里云百炼；百炼需对应地域和业务空间 ID，不能混用两个平台的 Key。
采用官方 WebSocket PCM 协议：输入 16kHz / 输出 24kHz / 16bit / 单声道；语义轮次 `smart_turn`。

## 使用

1. 千问平台首页 → 查看权益，查找**完全相同的模型ID**，确认有未过期额度，并确认“免费额度用尽即停”保护。未认证账号默认强制启用；已认证账号需手动开启。
2. 右键企鹅或托盘 → “实时语音配置”，选择“千问 AI 平台”，填写该平台 API Key；无需业务空间 ID。
3. 已完成第1步后勾选服务端开关确认项，保存。程序的确认项不能代替百炼服务端开关。
4. “持续语音对话”开始通话。程序不在启动时自动开启麦克风。
5. 可静音、打断、结束；关闭通话窗口也会停止收音并释放设备。

外放模式在AI生成/播放期间暂停输入，避免回录。耳机模式允许双向收音、语音打断；当前没有软件声学回声消除。
默认通话总时限4小时，10分钟无语音自动结束，配置可调整。断网最多连续尝试5次，然后停止。
会话连接满110分钟后在回复结束处续接，携带最多80条近期文字记录；记录只在内存中，结束后不保存。
Qwen-Audio模型原生音频历史容量与会话持续时长不同，不能保证长聊时记住所有细节。

## 免费额度保护

- 未确认当前平台、当前模型已开启服务端保护时，程序拒绝联网；百炼的仅免费模式只允许北京地域。
- 服务端返回 `AllocationQuota.FreeTierOnly` 或 HTTP 403 后结束，不重试，不转其他模型。
- 本地不能通过语音响应准确获知账号剩余额度，因此必须依靠平台服务端保护，不能靠估算Token防扣费。截图中的余额0元并不等同于用尽即停已启用。
- Key保存在Git忽略的 `ai_config.json`；不写日志，不提交Git。

## 单轮用量与通话界面（2026-10-14）

普通语音的 `ui/tts_engine.py` 保持本阶段开始时的内容，音色、语速、优先级和播放逻辑未改动。千问API只用于用户主动开启的语音通话。
通话窗口改为浅色卡片、现有企鹅形象、动态收音提示、聊天气泡和通话计时。
每轮读取 `response.done.response.usage`，展示服务端 `total_tokens`、输入/输出及文本/音频分项；不通过音频秒数估算真实用量。
被打断或未返回usage的轮次标为未知；累计有缺项时显示下界符号，不把缺项当0，也不把用量计数当账户剩余额度。
元数据保存到Git忽略的 `realtime_usage.log`，只含时间、模型和数字用量，不保存语音、对话文本或凭据。保留最近200轮详情与本次全部已报告用量累计。
旧版本没有保存之前各轮的usage，不能从本地准确补回；平台权益数据有分钟级延迟，以平台记录为准。

实测短句样例（合成通用问候，不使用用户录音）：输入音频2.96秒、回复4.88秒，单轮服务端总计254 Token，输入174、输出80。
另一文字输入/语音输出样例为224 Token（输入156、输出68），不能当作所有轮次固定消耗。
样例包含系统提示；正常长聊还可能含重复历史上下文，故长度相近的轮次也可能消耗不同。

计量依据：https://platform.qianwenai.com/docs/api-reference/qwen-audio-realtime/server-events
