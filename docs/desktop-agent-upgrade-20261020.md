# 咕嘎：通用电脑操作、长任务与动作升级

## 交互

重启咕嘎后，在「长语音 · 边聊边执行」里直接说任务。完整访问默认开启，可在软件权限页关闭；本机所有软件都可作为操作目标，不再要求逐个登记。是否成功操作取决于软件界面、进程权限和实际回执。

可尝试：

- “打开记事本，看一下窗口，输入一段中文，再检查有没有输入成功。”
- “读取这个项目，先列计划，在独立任务目录准备文件，用 PowerShell 执行测试。”
- 执行期间：“现在进度怎么样？”、“完成后再核对一次结果。”、“停止任务。”
- “摇摇头再回答我。”动作通过独立工具或结构化标记执行，语音只播报台词。

## 已实现能力

- `applications`：发现软件、按精确名称或 exe/lnk 绝对路径启动。
- `computer`：列窗口、聚焦、窗口截图、多模态观察、Windows UIAutomation 文本结构、点击、双击、拖动、滚动、组合键、Unicode 中文输入。
- 每次输入都引用最近 30 秒的观察 ID，核对前台窗口与位置；输入后要求重新观察。鼠标坐标是桌面物理像素，支持缩放截图的坐标换算及混合 DPI 线程上下文。截图只进入模型上下文，不落盘到任务日志。
- `local_computer`：文件读写和 PowerShell。专用写入工具保留备份、检查 Python/JSON 语法。单条命令最多 300 秒，取消或超时会终止其 Job Object 内子进程。
- `task_plan`：写计划和进展。默认单任务 15 分钟、最多 80 轮和 160 次工具操作；配置 `task_budget_seconds` 可设 30—1200 秒。达到预算保存检查点，不无限运行。
- 执行中可排队追加文字或语音要求，查询状态；一般语音打断仅中断旧播报。明确停止、结束通话、关闭窗口会取消任务。
- `runtime/agent-tasks/` 持久化计划、状态、有限操作回执及独立工作目录；说“继续”时读取同一会话检查点，并先验证现状。已完成副作用不自动重放；重启后不擅自恢复执行。
- 既有 MCP、项目会话、Edge TTS、自身源码备份修改及酒馆战棋工具保留。

独立任务目录和 Windows Job Object 提供产物、进程生命周期隔离，**不是限制所有文件和网络访问的操作系统安全沙箱**。完整访问继承当前咕嘎进程权限；未修改 UAC 或系统安全策略，也不能保证任意软件中的所有功能均能自动化。

## 动作

复用 `resources/expressions/` 的透明咕嘎图。新增 `head_shake`、`nod`、`tilt`、`wave`，保留原有跳跃等动作。摇头使用连续头部形变，变形在颈部渐弱，下半身固定。此阶段为 2D 动画，不是骨骼 3D 模型。

兼容清理 `咕嘎|摇头|台词`、`normal|head_shake|台词`、`（点头）台词`；自然语句中的“不要摇头”等词不会被误删。长语音新增静默动作工具，DeepSeek 的动作结果在语音开始播放时触发；送给语音模型的 answer 已去掉动作标记，提示词要求不口述舞台说明。

没有在用户 Pictures 顶层找到独立动作集（仅 Screenshots 目录），因此本次优先使用项目现有素材，未调用图片生成服务。

## 验证证据

- `test_agent_upgrade.py`：动作清理、语音动作去重、播报前清理、检查点恢复、超过旧六轮限制、执行中追加指令、多工具返回之后才附加截图、截图不进日志。
- `smoke_computer_control.py`：真实自有临时窗口完成截图、点击、中文输入、Ctrl+A 和按钮回执；测试窗口自动关闭，没有控制其他软件。
- 第二次实机窗口测试因前台切换而拒绝输入，未继续操作；失焦保护正常触发。
- `probe_agent_vision.py`：调用已配置官方 OpenCode Go URL 的 `deepseek-v4.1-flash` 一次，仅传人工合成的 `GUGA 7316` 图片，返回 `GUGA7316`，确认图像输入可用。
- `smoke_embodied_agent.py`：渲染 42 帧摇头，验证下半身像素固定、动作归位；生成预览 PNG 和 GIF。
- `smoke_pet_voice_bubble.py`：验证隐藏语音、点击返回、动作与开始说话同步、普通语音打断不取消任务、进度与追加要求、结束通话取消、真实 PowerShell 智能体调度。
- `smoke_agent_ui.py`：真实 Qt、MCP、自身操作与既有语音工具交接回归通过。

此阶段没有录制真实麦克风或替用户操作会议软件；真实端到端语音效果需重启咕嘎体验。未接入炉石盒子决策内核。
