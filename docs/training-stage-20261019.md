# 咕嘎战棋训练阶段报告：2026-10-19

目标：稳定前四、减少明显失误。用户授权本阶段最多 128 次已有 Go DeepSeek 请求，失败即停，不购买额外算力。**已运行真实离线训练，但尚无达到晋级标准的策略，未替换实战决策器。**

## 实际完成

- 现有后台/长语音升级保存为 Git `dbf9ad9`；普通 Edge TTS 没有被本阶段训练修改。
- CPU 完成两组实验，各 16 局规则示范、80 轮模仿训练、8 局 PPO、四种策略各 16 局评测。每组 88 局，报告和源码快照保存在对应输出目录。
- 另一批全新种子 `2041000..2041063`、轮换八个座位，对纯模仿模型和专家模仿模型做配对评测。每个模型的 64 局均对阵七个规则基线；只复用完全相同的基线结果，校验规则、种子及座位。
- 当前阶段实际调用 DeepSeek 24 次，24 次返回合法候选，报告用量 **26,885 tokens**；未继续耗尽剩余额度。没有据此承诺平台账单金额。共享台账预占请求次数，网络/HTTP/解析/候选失败后跨运行停止；中断留下的 pending 预约也阻止再次请求。
- 24 条专家输入通过零 API 调用重放全部还原，状态哈希及最终名次一致。专家选择是否合法与是否高水平分别记录，解释文字不作为训练真值。
- 115 项离线测试通过，包含固定引擎回放、云端台账、语音回归和晋级门槛；Qt 后台→动作回执→同通话播报集成检查通过。检查使用模拟后端，没有操作真实游戏。

## 64 局新种子结果

| 策略 | 平均名次，越低越好 | 前四率 | 有可出随从却结束回合 | 晋级 |
|---|---:|---:|---:|---|
| 规则基线 | 4.7031 | 47.92% | 0 | 对照 |

| 加 24 条 DeepSeek 标签的模仿模型 | 4.6484 | 46.88% | 0 | 未通过 |

纯模仿名次改善的配对 bootstrap 95% 区间为 **[-0.1719, 0.5938]**，包含零。专家模仿的区间为 **[-0.3984, 0.5391]**，同样包含零。不能说模型已显著强于基线，也不能说加专家标签必然有效或无效。

晋级门槛预置为：至少 64 局、名次改善区间下界大于零、前四率提升至少 5 个百分点。即使实验室通过，旧规则模型仍不能据此直接投入当前天梯。当前测试只覆盖一种简单对手，跨对手泛化尚未建立。

增加示范量和训练后，上一轮模型全部垫底的问题已消失；没有隔离每项改动的因果贡献。本轮 PPO 在 16 局诊断中也未稳定优于模仿模型，不强行推广 PPO 权重。

下一阶段优先完成当前版本规则和真实日志局面的对齐，约一个 20 分钟阶段，交付卡牌差异表与若干战吼/亡语/复生/圣盾回放夹具，不能承诺在这一阶段复刻完整战棋。随后逐批补法术、站位、发现和目标动作，以实体/效果特征代替只看 28 维数值的表示，再收集更有区分度的中后期专家样本。

本轮 24 条专家建议全部发生在较早回合，选择均为 BUY，监督多样性不足。继续大量复制这种样本价值有限。之后应比较升本/保血、卖买顺序、转型和站位，并在多种对手与保留种子上评估。战斗胜率由经过效果回归的规则模拟计算，运营前四率由多回合搜索与策略评测计算，不能用一个概率替代另一个。
