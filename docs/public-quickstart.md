# 咕嘎桌宠公开版快速开始

当前版本包含实时语音、通用桌面工具、可恢复长任务、头顶气泡、HearthMirror 只读棋盘和战棋离线实验室。下载后需要填写自己的模型 API 配置；仓库不包含任何 API Key。

## 1. 安装环境

- Windows 10/11。
- Python 3.10 或更高版本，推荐 3.12。
- 支持麦克风的输入设备和支持关闭回声的耳机或扬声器。

在项目目录运行：

```powershell
python -m pip install -r requirements.txt
```

下载后也可以直接双击 `启动企鹅.bat`，它会在缺少 PyQt5 或 edge-tts 时尝试安装依赖。

## 2. 配置两条模型链路

双击 `首次配置.bat`。脚本只在 `ai_config.json` 不存在时复制模板并打开记事本，不会覆盖已有配置。

### 聊天与任务模型

填写 OpenAI Chat Completions 兼容接口：

```json
{
  "api_key": "YOUR_CHAT_API_KEY",
  "base_url": "https://YOUR_OPENAI_COMPATIBLE_ENDPOINT/v1",
  "model": "YOUR_CHAT_MODEL_ID"
}
```

该模型负责任务规划、工具调用、文件/桌面操作和最终回答。视觉控制还需要兼容图片输入的多模态模型；如果只使用 UIAutomation 结构化控件，可以不依赖截图视觉模型。

### 端到端实时语音

填写千问 AI 平台的实时语音配置：

```json
{
  "realtime_voice": {
    "provider": "qianwen",
    "model": "qwen-audio-3.1-realtime-plus",
    "api_key": "YOUR_REALTIME_VOICE_API_KEY",
    "voice": "longanqian_v3.1",
    "free_only": true
  }
}
```

实时语音负责麦克风收音、轮次检测、自然语音和打断；聊天模型负责真正的任务与工具调用。两边的 Key 分开填写，不要混用。

使用免费额度时，先到千问平台权益页为**完全相同的模型 ID**开启“免费额度用尽即停”，再在咕嘎的“实时语音配置”中确认平台和模型。程序无法代替平台侧开关；未确认时不会联网。使用付费额度时，需要自行确认所选模型权限和计费方式。

### 可选视觉模型

桌面截图定位和战棋看画面使用 `zhipu_api_key` / `vision_model`。只做文本任务和 UIA 控件操作时可以不填。模型名称与权限以对应平台文档为准。

## 3. 启动

双击 `启动企鹅.bat`。脚本会请求管理员权限；本机授权和系统权限策略决定实际能操作哪些软件。授权模式继承咕嘎 Python 进程的 Windows 权限。

启动后：

1. 右键桌宠 → `对话 · 咕嘎智能体`。
2. 打开 `软件权限`，确认完整访问范围。
3. 点击 `语音对话`，允许麦克风。
4. 直接说任务，例如“打开记事本，读取当前窗口，输入一段中文，再检查输入是否成功”。

## 4. 安全与数据

- `ai_config.json`、`runtime/chat/`、`runtime/agent-tasks/`、任务命令输出和战棋审计均被 Git 忽略。
- 工具输出中常见密钥字段会脱敏，截图不写入任务日志。
- 所有模型操作都应经过工具执行和结果回执。当前新增完成门槛：未复查的桌面输入或失败副作用不会显示为“已完成”。
- 打开第三方软件只代表 Windows 接受启动请求；是否成功打开、是否完成软件内部动作，以窗口和工具回执为准。

## 5. 常见问题

**语音按钮提示配置未确认**：检查 `provider`、`model` 与平台权益页是否完全一致，并确认免费额度用尽即停。

**模型返回 HTTP 401/403**：检查聊天和实时语音是否分别使用正确的 Key、接口地址和模型 ID。

**能对话但不能看屏幕**：当前聊天模型可能不支持图片输入，或未配置视觉模型。可先使用 `computer.accessibility` / `computer.uia` 走结构化控件路径。

**管理员程序无法被普通权限咕嘎操作**：用同一管理员权限启动咕嘎；操作系统不会允许低权限进程向高权限窗口发送输入。
